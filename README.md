# My Neovim Configuration

A minimal Neovim setup built from scratch.

## Features

- Gruvbox colorscheme
- Tree-sitter highlighting
- Rust, Python, and Lua support
- LSP and autocompletion
- Automatic formatting on save
- Oil.nvim file explorer
- fzf-lua fuzzy finding
- Flash navigation
- mini.surround

## Performance

Average startup time: 47.5 ms
